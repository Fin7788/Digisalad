# Digisalad

This project uses [Vite](https://vitejs.dev/) and [Vue 3](https://vuejs.org/).

## Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Production Build

1. Build the project for production:
   ```bash
   npm run build
   ```
2. Preview the built app locally:
   ```bash
   npm run preview
   ```
